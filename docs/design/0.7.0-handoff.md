## 2. 바탕: 코어는 투명, 글자는 어둡다

- 코어는 패널 뒤를 칠하지 않는다. Unity 런타임 패널도 뒤가 비어 게임 화면이 보인다 [확인 root 배경 투명].
- 런타임 테마의 글자는 #1b1b1b다. **어두운 바탕(VSCode 어두운 테마 등)에 그대로 올리면 글자가 거의 안 보인다** [추론].
- 바탕을 무엇으로 채울지는 화면을 보여 주는 쪽이 정한다. 이 저장소의 플레이그라운드는 런타임 테마일 때 패널 뒤에 투명을 뜻하는 체크무늬(흰색·#cccccc)를 깐다. 에디터 테마는 예전처럼 어두운 바탕이다.
- 예전 모습이 필요하면 `theme: 'editor'`를 넘긴다. 다만 0.6.1과 똑같지는 않다(에디터 테마 값이 측정값으로 채워졌다).

## 4. 소비자가 판단할 것 (제안 아님, 목록)

1. 바탕: 런타임 테마에서 어두운 글자가 보이도록 패널 뒤를 무엇으로 칠할지
2. 테마 선택: 사용자에게 `runtime`/`editor`를 고르게 할지, 하나로 고정할지
3. (해결됨 — 코어가 테마 적용 경고를 없앴다. `version-dependent` 채널을 시험하는 픽스처는 표본을 바꿔야 한다)
4. 스냅숏·픽스처: 기본 테마로 그린 기대 화면이 있으면 다시 만들지, `theme: 'editor'`로 고정할지
5. 지원 컨트롤 목록: GroupBox·Box(묶음 B), TextField(묶음 C)가 `supportedControlNames()`에 들어갔다. 스킬 문서의 목록과 "믿어도 되는 좌표" 설명, "TextField는 그릴 수 없다"는 문장
6. **스킬 문서의 "TextField를 그릴 수 없다"는 서술이 이제 틀렸다**(묶음 C). uxml-author docs 검사 "TextField is called undrawable and really is"가 이것을 잡는다. 스킬의 할 일: 그 문장을 지우고 TextField를 지원 목록과 "믿어도 되는 좌표" 설명에 넣는다. 커서·선택 표시는 그리지 않는다는 것도 함께
7. **Slider·SliderInt도 그린다**(묶음 D). 스킬 문서의 "Slider는 그릴 수 없다"와 지원 목록. vscode는 미지원 컨트롤의 예를 Slider 대신 아직 폴백인 컨트롤(Toggle·DropdownField 등)로 바꿔야 한다 — 묶음 E(Toggle) 뒤에는 DropdownField
8. **Toggle·RadioButton도 그린다**(묶음 E). 두 소비자의 미지원·크기 0 표본을 0.7.0에서 그리지 않는 컨트롤(MinMaxSlider·Foldout·DropdownField)로 바꿔야 한다
9. **ProgressBar·TextElement·RepeatButton도 그린다**(묶음 F). 스킬 문서의 지원 목록. RepeatButton은 Unity처럼 맨 글자로 보인다는 것도 함께

## 5. 코어 쪽에 남은 질문 (이 저장소)

- ~~런타임 테마에서 테마 경고가 필요한가~~ — **해결됨(2026-10-17).** 테마 값을 적용했다는 사실만으로는 경고하지 않는다. 경고는 측정으로 확인된 차이에만 낸다(`tests/contract-070/theme-warnings.test.ts`).
- **`:root` 경고의 kind — 바꾸지 않는다(2026-10-17 사람 결정, 검토 R3).** kind `version-dependent`·reason `matches-unity` 그대로 둔다. 버전 차이가 아니므로 kind는 사실과 다르지만, 제안했던 `unsupported-selector`도 사실과 다르다(`:root`는 지원되고 Unity와 같게 동작한다).
  - 소비자는 **reason을 기준으로** 읽는다 [확인, 코드 읽기]: uxml-author(`d430ff3`) `classify()`와 vscode-uxml-preview(`ce8ea27`) `webview/warnings.ts` 모두 `matches-unity`를 kind보다 먼저 나눈다. 따라서 할 일 없음.
  - `docs/api.md` 경고 절에 "kind는 역사적 이름, reason이 기준"을 적었다. 맞는 kind 신설은 `WarningKind`를 바꿀 수 있는 다음 큰 버전(`docs/backlog.md` 0.7.0 절).
