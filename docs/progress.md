## 다음 할 일

Phase 3 착수 — "이 요소에 최종적으로 어떤 스타일이 적용되는가"를 계산한다.

1. 셀렉터 매칭. `SimpleSelector`의 `unknown`이 하나라도 있으면 **그 규칙 전체를
   무시하고 경고**한다 (파서는 이미 담아뒀다)
2. 우선순위 계산. 인라인 > `#name` > `.class` > 타입 > `*`,
   동률이면 **뒤에 나온 규칙**이 이긴다
3. 상속 처리
4. `var()` 커스텀 속성
5. shorthand 전개 — **모델이 아니라 여기서 한다.** `padding: 6px 14px`는
   문자열 그대로 저장돼 있다
6. 인라인 `style` 속성 파싱 — 노드에 저장하지 않고 여기서 매번 읽는다
7. 출처(`StyleOrigin`) 기록 + `explain` 경로 (같은 함수, 후보를 버리지 않고 모음)

**계산 결과를 모델에 쓰지 않는다.** 별도 자료구조로 반환한다.
우선순위 테스트 20개 이상이 DoD다.
