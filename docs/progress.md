Phase 2 착수. 순서:

1. **테스트 픽스처를 먼저 만든다** (절대 규칙 5). 10개 이상.
   주석, 속성 순서, 자기닫힘 태그, 미지원 컨트롤, CRLF 파일을 포함시킨다
2. UXML 파서 → `ElementNode` 트리 + 스팬 3분할
3. USS 파서 → `StyleSheet`
4. 직렬화 — clean 노드는 `source`에서 슬라이스
5. 왕복 테스트. **편집 없는 왕복은 바이트 일치여야 한다.**
   스팬 재출력이 맞다면 정의상 그렇게 나온다. 안 나오면 파서가 스팬을 잘못 잡은 것이다

**파서는 판단하지 않는다.** 미지원 컨트롤·속성·셀렉터를 전부 읽어서 담기만 하고,
"지원하는가"는 아래 단계에 맡긴다. 판단이 파서에 섞이면 지원 범위가 바뀔 때마다
파서를 고쳐야 하고, 파서를 고치면 왕복이 위험해진다.
